# Code of Conduct

## Our standard

This project adopts the **Contributor Covenant, version 2.1** as its code of
conduct. The full text is published at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

It is adopted here by reference rather than copied, so that the version you read
is the canonical one and cannot drift from a stale copy in this repository.

In short: participate in a way that makes other people willing to keep
participating. Harassment, personal attacks, and demeaning or exclusionary
behaviour are not acceptable, in issues, pull requests, reviews, or anywhere else
this project is discussed.

## Scope

This applies in all project spaces — issues, pull requests, code review,
discussions — and whenever someone is representing the project in public.

## Reporting

Report a concern to the maintainer at **mcclain.thiel@gmail.com**. Reports are
handled privately. You will get an acknowledgement, and you will not be asked to
justify raising something in a public thread.

The maintainer is responsible for enforcement and may edit, remove, or reject
contributions and comments that violate this policy, and may ban a contributor
temporarily or permanently for behaviour they consider inappropriate.

If your concern is *about* the maintainer, you can report it to GitHub directly:
<https://support.github.com/contact/report-abuse>.

## A note on scientific disagreement

This project is about research tooling, so disagreement about methods, evidence,
and correctness is the point, and vigorous technical argument is welcome. Say the
work is wrong and why. Don't make it about the person who wrote it.
