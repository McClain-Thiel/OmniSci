# Literature review

Define the question, scope, date range, study types, and inclusion/exclusion
criteria before broad searching. Record the actual queries and databases or
search engines used so the review can be updated.

Prefer primary studies for empirical claims and authoritative reviews for
orientation. For each important claim, check the source itself and capture:

- population or system;
- intervention/exposure and comparator;
- outcome and effect estimate;
- design, sample size, uncertainty, and major limitations;
- whether the source supports, contradicts, or only contextualizes the claim.

Separate consensus, active disagreement, and missing evidence. Do not count
several papers using the same cohort or dataset as independent replications.
Never cite a paper from title/snippet relevance alone.

Return a concise synthesis plus an evidence table when the task is broad enough
to benefit from one.
